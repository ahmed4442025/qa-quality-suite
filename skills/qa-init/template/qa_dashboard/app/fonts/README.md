# Local dashboard fonts

Cairo (weights 400–800) and JetBrains Mono (weights 400–600) are bundled as
variable WOFF2 subsets. `../css/fonts.css` preserves their Unicode ranges, so
browsers load only the subsets used by the page. No external font request is
needed.

Source: https://fonts.googleapis.com/css2?family=Cairo:wght@400..800&family=JetBrains+Mono:wght@400..600&display=swap

Downloaded on 2026-09-21 from Google Fonts. Both families use the SIL Open Font
License; see `Cairo-OFL.txt` and `JetBrainsMono-OFL.txt` for their copyright and
license notices. Keep the font files and notices together when copying the
dashboard template.
